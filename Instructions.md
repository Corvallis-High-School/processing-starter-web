# Instructions

## Make a Fork of this repository
   1. Append your GitHub username to the new Repository name
      - If your username is StudentCHS, the new repository will be processing-starter-web-StudentCHS
   2. Make sure to select Corvallis-High-School as the owner of this repository
      - You should have received an invitation to join Corvallis-High-School
      - This way you do not need to add me as a collaborator
      - You will also be able to take advantage of more Codespaces allocations

## Processing sketch lifecycle

- `settings()` configures the sketch, including its window size.
- `setup()` runs once when the sketch starts.
- `draw()` runs repeatedly while the sketch is running.
- `keyPressed()` called once every time a key is pressed. The key that was pressed is stored in the key variable.
